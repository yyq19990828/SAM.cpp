# Archived v2/v3 precision policies

These files retain historical quality tiers, hard thresholds, campaign rules
and quality-dependent performance qualification for interpreting earlier
receipts. They are archived, outside the current validation and benchmark
entry points. Old grouped and flat policy commands have been removed; do not
use this archive to choose current quantization configurations.

Use the [application benchmark](../../benchmark/quantization_benchmark.py)
for independent reference agreement, performance measurement and precision
inspection. See its [guide](../../../docs/quantization-benchmark.md).

The two policy JSON documents retain their exact historical bytes and hashes.
The archived Python implementations have relocated imports and repository
paths; relocation does not make an old result a new qualification. Existing
machine-readable results and frozen producer snapshots remain unchanged in
their original, separately retained evidence directories.

Earlier experiment procedures and decisions remain in the
[v3 plan](../../../docs/plans/20261010-101413-precision-acceptance-v3.md).
